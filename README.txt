陽気ぐらしへの道 v1.1

目的：天理教の教えを手掛かりに、毎日の心遣いを振り返り、AIとの対話を通して考えを深め、明日の小さな実践につなげる365日型教材。

AIとの対話：Webページ自体がAIと自動通信する仕組みではありません。「AI対話を始める」ボタンで、その日のテーマを含む対話用プロンプトをコピーし、ChatGPT等の同じチャットに貼り付けて対話します。2日目以降は同じチャットを続けることで、前回の振り返りを踏まえやすくなります。

構成：index.html（トップ）／start/index.html（365日教材）／curriculum.js（365日データ）／陽気ぐらしへの道_基本憲章.md／陽気ぐらしへの道_AI教師マスタープロンプト.md

注意：本教材は天理教公式資料を基礎資料として構成する学習・自己省察用の試作です。AIの回答を天理教の公式見解とみなさないでください。病気・事故・不幸などの原因を断定せず、必要な場合は専門家や関係機関への相談を優先します。

ローカルHTMLでも教材部分は動作するよう、ページ遷移を相対リンクで構成しています。PWAのService WorkerはHTTPS等の安全なオリジンで使用してください。


【v1.3変更点】
ChatGPT連携導線を簡略化しました。
「今日のAI対話を始める」ボタンで今日のプロンプトをクリップボードへコピーし、同時にChatGPTを新しいタブで開きます。
ChatGPT側では、同じチャットを開いてCtrl+V（スマートフォンは貼り付け）し、送信します。
※外部WebページからChatGPTの入力欄へ自動入力・自動送信する機能は使用していません。


【v2.0変更点】
・365日教材の通常表示を「次の日」方式からカレンダー日付による自動判定方式へ変更。
・コース開始日を2026年9月30日＝第1日として設定。以後、経過日数から第○日を自動表示。
・毎日Webで「次へ」を押す必要をなくし、ChatGPTでは「今日、陽気ぐらしへの道を始めよう」という掛け声で開始できる構成を案内。
・AI寺子屋と同じく「問い→受け止め→深掘り→別の視点→もう一度考える→小さな実践」の対話方式を開始プロンプトに反映。
・個別の日を確認するための ?day=1 ～ ?day=365 は残していますが、通常利用では自動判定を使用します。
・365日目以降は第365日の内容を表示します。
